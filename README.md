A router is a network device that forwards data packets between different networks.
It operates at Layer 3 (Network Layer) of the OSI model.
The router examines the address field in the packet header to determine the correct output channel for forwarding the packet.
The diagram in the image illustrates:
A source server network sending data.
The router receiving a packet (p1) and forwarding it based on its IP address.
Packets being directed toward different destination client networks based on their addresses.
